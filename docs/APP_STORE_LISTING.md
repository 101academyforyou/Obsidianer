Obsidianer is an unofficial, offline learning app that teaches beginners how to use the note-taking app Obsidian. It is not affiliated with Obsidian (Dynalist Inc.); this is stated at the top of the description and in the app.

No account or sign-in is required. All lesson content is bundled in the app and works fully offline. The app collects no data and contains no ads.

Native, interactive features beyond static content:
- Swipeable full-screen feature cards (home screen) with haptic feedback
- 19 interactive lessons, each with a built-in Markdown editor and live preview that checks practice goals automatically
- Quizzes with explanations; completing them unlocks XP, levels and 11 badges
- An interactive, draggable knowledge graph
- A Markdown playground that can export .md files

How to review: swipe up on the home screen, tap any card (e.g. "雙向連結 [[ ]]") to open its lesson, scroll down to the practice editor and quiz.
